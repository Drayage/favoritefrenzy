# 🐾 최애 쟁탈전 · Favorite Frenzy

> 오늘의 쓰담왕은 누구? — 귀여운 반려동물 전략 카드게임

집사의 관심을 독차지하기 위해 반려동물들이 모였다! 같은 펫을 모아 **관심 폭발**을
일으키고, 다른 펫을 밀어내 **쓰담(점수)** 을 가장 많이 모으면 승리한다.
5분이면 배우고, 20분이면 웃으며 즐길 수 있는 가벼운 전략 카드게임.

순수 HTML/CSS/Vanilla JS로 만든 **모바일 우선 PWA**다. (빌드 도구·프레임워크 없음)

---

## ✨ 특징

- 🎮 **로컬 플레이** — 1명 + AI 1~3명, 또는 같은 기기 핫시트(최대 4명)
- 🤖 **AI 난이도 3종** — 쉬움 / 보통 / 어려움
- 🌐 **온라인 멀티플레이** — Firebase Firestore 실시간, 방 코드 공유로 2~4인
- 🎬 **리플레이** — 최근 10게임 자동 저장, 단계 재생(x1/x2/x4), **JSON 내보내기/불러오기**
- 📱 **PWA** — 홈 화면 설치, 오프라인 플레이(서비스워커 캐시)
- 🎨 직접 그린 **인라인 SVG 아트** + 파스텔 감성 UI + 통통 튀는 애니메이션

## 🃏 게임 규칙 요약

**카드(총 70장)**: 반려동물 8종 × 8장(64) + 특수 6장.

**관심 순위**(높을수록 강함): `8 고양이 › 7 강아지 › 6 토끼 › 5 햄스터 › 4 앵무새 › 3 기니피그 › 2 페럿 › 1 고슴도치`

**턴**: 아래 둘 중 하나만 수행 → 손패 5장까지 드로우
1. 같은 반려동물 카드를 1장 이상 그 존에 플레이
2. 특수카드 1장 플레이

**관심 폭발 & 밀어내기**: 한 존이 **3장 이상**이 되면 폭발 → 자신보다 아래 순위 중
**가장 가까운 살아있는 존**을 밀어낸다(빈 존은 건너뜀). 밀려난 카드는 모두 내 쓰담 더미로(1장=1쓰담).
🦔 **고슴도치**는 예외로 **고양이**만 밀어낼 수 있다(고양이가 없으면 실패).

**특수카드**
| 카드 | 효과 |
|---|---|
| 🦎 카멜레온 ×2 | 아무 반려동물로 변신해 합산 가능(폭발 포함) |
| 🧸 장난감 ×1 | 선택한 존의 카드 전부 제거(폐기) |
| 🎪 장난꾸러기 ×1 | 상대와 손패 전부 교환 |
| 🛏️ 침대 아래 ×1 | 다음 밀어내기 1회 방어(방어 성공 시 침대 아래 카드는 공격자 쓰담으로, 1점) |
| 🏅 최애 배찌 ×1 | 지정한 펫이 밀려날 때마다 +1 쓰담(게임 끝까지) |

**종료**: 드로우 더미가 소진된 후, 어느 한 플레이어의 손패가 0장이 되면 종료. 쓰담(획득 카드 수) 최다 승리!

## 🚀 실행 / 배포

### 로컬 실행
ES 모듈을 쓰므로 정적 서버가 필요하다(파일 직접 열기는 CORS로 막힘).
```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000
```

### GitHub Pages 배포
1. 이 저장소를 GitHub에 푸시한다.
2. **Settings → Pages → Source** 에서 배포할 브랜치(예: `main` 또는 현재 작업 브랜치)와 `/ (root)` 를 선택한다.
3. 잠시 후 `https://<사용자>.github.io/<저장소>/` 에서 플레이 가능. (모든 경로가 상대경로라 서브패스에서도 동작)

## 🔥 온라인 멀티플레이 (Firebase)

설정 키는 `js/firebase-config.js` 에 들어 있다. (웹 API 키는 공개용으로 설계되어 노출돼도 안전)
실제 보안은 **Firestore 보안 규칙**으로 적용한다. Firebase 콘솔 → Firestore → 규칙에 아래처럼 설정:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    // 방 문서: 게임 진행용. 필요 시 시간 제한/검증을 더 강화하세요.
    match /rooms/{code} {
      allow read, write: if true;   // 데모용. 운영 시에는 인증/검증 규칙 권장.
    }
  }
}
```

> ⚠️ 위 규칙은 누구나 읽기/쓰기가 가능한 **데모용**입니다. 운영 환경에서는 Firebase
> 익명 인증 + 방 참가자 검증으로 강화하는 것을 권장합니다.

**동작 방식**: 방 문서에 `(seed, configs, log[])` 만 공유한다. 모든 클라이언트가 동일한
결정적 엔진으로 상태를 재구성하므로, 현재 차례인 플레이어가 자기 액션을 `log` 에 추가하면
`onSnapshot` 으로 모두 동기화된다.

## 🗂 프로젝트 구조

```
index.html            화면 골격(메뉴/설정/게임/결과/리플레이/온라인)
css/styles.css        파스텔 테마 + 반응형 + 애니메이션
manifest.json, sw.js  PWA(설치/오프라인)
icons/, favicon.svg   직접 그린 SVG 아이콘
js/
  rng.js              결정적 시드 PRNG (리플레이/멀티 재현)
  cards.js            카드/펫 정의, 덱 빌더
  art.js              인라인 SVG 아트(펫 8종 + 특수 + 로고)
  engine.js           순수 규칙 엔진 (AI/리플레이/멀티 공용)
  ai.js               난이도별 AI
  ui.js               렌더링 + 애니메이션
  controller.js       턴 진행(로컬 AI/핫시트 + 온라인)
  replay.js           리플레이 재생
  storage.js          localStorage + 내보내기/불러오기
  firebase.js         Firestore 멀티플레이
  firebase-config.js  Firebase 설정
  main.js             진입점/라우팅
test/engine.test.mjs  엔진 규칙 회귀 테스트
```

## ✅ 테스트

node test/engine.test.mjs   # 핵심 규칙(폭발/래핑/방석/배지/재구성) 검증
